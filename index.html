Setup Backend Google Drive & Sheets

Gunakan kode ini di Apps Script agar berkas dan data pendaftar otomatis masuk ke Google Drive & Spreadsheet.

Langkah Penting Deployment Apps Script:

  1. Buka Google Spreadsheet Pendaftaran Anda.
  2. Klik menu Ekstensi > Apps Script.
  3. Hapus semua kode bawaan, lalu **paste kode di bawah**.
  4. Ganti ID_FOLDER_DRIVE (baris 10) dengan ID folder Google Drive tempat menyimpan berkas pendaftar.
  5. Klik Terapkan (Deploy) > Aplikasi Web Baru (New deployment).
  6. Ubah Jalankan Sebagai (Execute as): Saya (Me).
  7. Ubah Siapa yang memiliki akses (Who has access): Siapa saja (Anyone).
  8. Klik **Deploy**, izinkan akses akun Google, lalu salin URL Aplikasi Web ke variabel `SCRIPT_URL` di HTML ini.
